Qress-ent Admin

This is a placeholder for the future CMS / admin dashboard.

Planned capabilities

  • Secure login
  • Manage products (add / edit / delete / photos / prices)
  • Manage articles (create / publish / categories)
  • Edit homepage copy, CTAs, contact details
  • Upload & organise images
  • Manage testimonials
  • Site settings (WhatsApp number, social links, logo, currency)

Recommended next implementation

For lowest cost and full control:

  1. Cloudflare Pages + D1 + R2 + Workers (very cheap / free tier)
  2. or Supabase (free tier, auth + database + storage)
  3. or PocketBase (self-hosted, single binary)

The current static site is structured so any of these can be added without redesigning the public pages.

Do not put real credentials or admin logic in public JavaScript. Authentication must live on the server side.
